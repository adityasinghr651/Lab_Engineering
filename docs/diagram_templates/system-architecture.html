DevFlow Architecture & Request Lifecycle Production Layering

Layered Node.js / Express 5 REST API with PostgreSQL connection pooling, JWT RBAC, and Zod validation

Node.js 22+
Express 5
PostgreSQL 16
Zod v4
JWT / bcrypt
1
Client & Entry
HTTP / REST Clients
REST Consumer
Frontend SPA, mobile clients, and cURL / Postman callers sending JSON bodies and Bearer JWTs.
Port 3000 Gateway
Configured via process.env.PORT in server.js with Express 5 application instance.
Global Middleware
express.json() body parsing + requestLogger capturing method, URL, status, and duration.
ENABLE_REQUEST_LOGGING
2
Security Guards
src/middleware/
Rate Limiter 429
Sliding-window limiter on POST /auth/login. Caps brute-force attempts to 5 per 15 min with Retry-After.
JWT Authenticate 401
Extracts Bearer token, verifies against JWT_SECRET, and attaches req.user = { id, email, role }.
RBAC Authorize 403
Role check middleware: authorize('admin') gates administrative stats and elevated mutations.
Zod Validator 400
Validates payload schemas for Auth, Projects, Issues, and Comments; fails early with field details.

Ops & Health

4
Domain & Services
src/services/ & controllers/
auth.service.js
Bcrypt hash (10 rounds), public role immutability (always member), JWT token generation with expiration.
project.service.js
Unique key verification, project lifecycle, ownership authorization checks for updates and deletions.
issue.service.js
Resource-level authorization: creators, project owners, or admins can update status/priority or delete issues.
comment.service.js
Issue association validation, author/admin deletion boundaries, cascade cleanup handlers.
5
Data Access Tier
src/repositories/
user.repository.js
Parameterized SQL queries: findByEmail, findById, create. Prevents SQL injection.
project.repository.js
Relational joins with users for owner metadata; unique key collision handling via code 23505.
issue.repository.js
Dynamic query builder: ILIKE search across title/description, multi-filter conditions, deterministic ORDER BY …, i.id ASC, and windowed COUNT(*) OVER() pagination.
comment.repository.js
Chronological comment streams joined with author profiles.
6
PostgreSQL Tier
src/config/db.js
Connection Pool
Bounded pg.Pool managing concurrent client connections:
max: 20 | idle: 30s | timeout: 5s
users table
id (PK), name, email (UQ), password_hash, role (admin/member), timestamps.
projects table
id (PK), name, key (UQ), owner_id (FK → users.id ON DELETE CASCADE).
issues table
id (PK), title, status, priority, project_id (FK), creator_id (FK), assignee_id (FK).
comments table
id (PK), issue_id (FK → issues.id), user_id (FK → users.id), content.
⚠️

Centralized Error Handling Architecture (src/middleware/errorHandler.js)

Custom AppError operational codes, Zod validation formatting (400), PostgreSQL duplicate key 23505 (409 Conflict), JWT expiry (401), and sanitized 500 internal server error shielding.

🛡️

Resilience & Lifecycle Management (server.js & src/config/)

10s Bounded Graceful Shutdown watchdog (terminates hung connections on SIGTERM/SIGINT), boot-time JWT secret fail-fast validation in production, and optional connection pool latency metrics (TRACK_POOL_METRICS).
